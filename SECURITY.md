# Security Policy

Please report vulnerabilities privately via GitHub: **Security → Report a vulnerability** on this repository (https://github.com/gonglian8-stack/bip39-ai/security/advisories/new). Do not open a public issue.

Include the version from the site footer (or the offline file name) and steps to reproduce. We aim to acknowledge reports within 7 days.

The security model and its limits are described at https://bip39.ai/security/.
